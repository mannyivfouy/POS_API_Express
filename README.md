# Precision POS Backend

Backend API for Precision POS — a modern Point of Sale and Inventory Management System built with Node.js, Express, TypeScript, and MongoDB.

## 🚀 Features

- 🔐 JWT Authentication
- 👥 Role-Based Access Control (RBAC)
- 🛡️ Permission-Based Authorization
- 🔒 IP-Based Login Attempt Protection
- 📦 Product Management
- 🏷️ Category Management
- 👤 User & Staff Management
- 🧾 Customer Management
- 🚚 Supplier Management
- 🛒 Purchase Management
- 💰 Sales Management
- 💳 Payment Processing
- 📱 Bakong KHQR Payment
- 📩 Telegram Notifications
- 📊 Stock Management
- ✅ Request Validation with Zod
- 🖼️ Image Upload with Multer
- 🌐 RESTful API

## 🛠️ Technologies

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- JWT
- bcrypt
- Zod
- Multer
- Axios
- Bakong KHQR
- Telegram Bot API
